# AI Use Policy

This policy describes AI-assisted development expectations for this repository.

## Policy Intent

- Maintain ownership clarity for all committed code.
- Require human review and validation for AI-assisted changes.
- Preserve reproducible technical evidence through tests, proof scripts, and CI artifacts.

## Requirements

1. AI-assisted changes must be reviewed by a maintainer before release packaging.
2. AI-generated code must pass existing quality gates (build/test/proof/release checks).
3. Security-sensitive or determinism-critical logic requires explicit human validation.
4. License and provenance constraints remain unchanged for AI-assisted contributions.

## Non-Goals

- This policy is not a legal transfer or licensing document.
- This policy does not replace chain-of-title diligence processes.
