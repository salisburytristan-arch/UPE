# UPE One-Page Sales Sheet

## What It Is

UPE is a deterministic native physics and simulation runtime built for rollback-capable gameplay, auditable evaluation, and source integration without mandatory runtime dependencies.

## Why Buyers Care

- Reproducible stepping, replay, snapshots, and state hashing.
- C++20 engine core with a stable C API boundary.
- Proof-backed evaluation artifacts for diligence.
- Broad simulation surface: rigid bodies, collision, CCD, fluids, cloth, vehicles, character control, and diagnostics.

## What Is Proven

- Determinism and rollback tooling are in-repo and documented.
- Benchmark and proof flows generate machine-readable artifacts.
- Collision and CCD demos show actual solver paths.
- Performance outputs now include JSON, CSV, Markdown, and HTML.

## What Comes In The Package

- Core runtime source.
- Docs and buyer-facing trust materials.
- Verification scripts and benchmark entry points.
- Example programs for evaluation.

## Commercial Posture

- Source licensing is the default posture.
- Ownership and exclusivity are handled by separate agreement when applicable.
- Pricing is negotiated by scope, support, and rights requested.

## Best Fit Buyers

- Engine teams.
- Simulation and robotics teams.
- Studio technical directors.
- Buyers who need deterministic rollback and documentation they can inspect.
