# MODULE STABILITY

This document separates modules by current evaluation confidence.

## Stable

- Core math and geometry helpers
- World lifecycle and step control
- Bodies, shapes, and core collision queries
- Constraint and joint basics
- Deterministic replay and state hashing surface
- Memory context and diagnostics surface
- Test harness and build scripts

## Beta

- Character controller and vehicle workflows
- Cloth and rope systems
- Fluids and buoyancy
- Benchmark scenes and performance gates
- Serialization and snapshot workflows
- Telemetry and profiling utilities

## Experimental

- Broad scientific expansion modules
- Advanced coupling and multi-domain orchestration
- GPU compute paths
- Optional language bindings that depend on external runtimes
- Visual capture and showcase-only demo paths

## Prototype

- Future roadmap ideas that are not yet part of the buyer-critical validation path
- New platform ports without a validated proof lane
- Large-scale editor or browser delivery targets that have not been proven in this repo
